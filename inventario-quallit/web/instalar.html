Registrar este computador no inventário

Leva menos de 1 minuto e você não precisa preencher nada: o sistema reconhece sozinho memória, disco, Windows, número de série e o resto.

  1. 1

    Baixe o instalador

    Um arquivo pequeno, já configurado para este computador.

  2. 2

    Abra o arquivo baixado

    Clique no arquivo que apareceu nos downloads do navegador (ou aperte Ctrl + J).

    Inventario-Quallit.cmd
    Apareceu um aviso?
    • Navegador perguntou se quer manter o arquivo → clique em Manter.
    • “O Windows protegeu o computador” → clique em Mais informações e depois em Executar assim mesmo.
    • “Deseja executar este arquivo?” → clique em Executar.

    Uma janela preta abre, mostra o progresso e fecha sozinha. É normal.
