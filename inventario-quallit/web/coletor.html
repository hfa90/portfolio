Falta a chave do link

Esta página só funciona pelo link gerado no painel, que termina com uma chave longa (…coletor.html#k=…).

  1. No painel: Coleta → Como coletar → Coletores de dados Android → Link para o coletor.
  2. Toque em Copiar link (ou envie pelo WhatsApp) e abra esse link no navegador do coletor.

Registrar coletor de dados

Abra esta página no navegador do coletor. Bipe a etiqueta do nº de série (atrás do aparelho ou embaixo da bateria) e a do patrimônio. O modelo e a versão do Android são lidos sozinhos.

Esta página lê apenas dados técnicos do aparelho (modelo, versão do Android e carga da bateria). Nada é instalado.
